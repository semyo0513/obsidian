BLE PROXIMITY FINDER

따뜻해요, 차가워요

블루투스 신호 세기로 잃어버린 기기에 가까워지는지 확인하는 도구예요

⚠️ 이 파일을 그냥 열면 작동하지 않아요 Web Bluetooth는 보안 연결(HTTPS 또는 localhost)에서만 동작해요. 아래 중 한 가지 방법으로 실행해주세요.
  • 터미널에서 이 파일이 있는 폴더로 이동한 뒤 python -m http.server 8000 실행 → 브라우저에서 http://localhost:8000 접속
  • 또는 GitHub Pages 등에 업로드해서 https 주소로 접속
⚠️ 이 브라우저는 지원하지 않아요

도움말 / 사용 전 확인사항

지원 브라우저

  • Chrome, Edge, 삼성 인터넷 (Android·Windows·macOS)에서 동작해요.
  • Safari, Firefox, iOS의 모든 브라우저(아이폰·아이패드)에서는 Web Bluetooth를 지원하지 않아 사용할 수 없어요.

실행 방법

  • 이 파일을 더블클릭해서 바로 열면 보안 정책 때문에 작동하지 않아요. 로컬 서버(예: python -m http.server)나 GitHub Pages처럼 https 또는 localhost 주소로 열어야 해요.

기기 이름을 모를 때

  • 이름 필터를 비워두고 시작하세요. 선택 창에 주변의 모든 블루투스 기기가 목록으로 뜨는데, 대부분의 브라우저는 목록에 신호 세기 아이콘(막대)도 같이 보여줘요. 막대가 많이 채워진(신호가 강한) 기기부터 순서대로 시도해보세요 — 잃어버린 기기는 대개 가까이 있으니까요.
  • 이름이 "Unknown" 이나 임의의 코드로 표시될 수 있어요. 정상이에요 — 제조사가 기기 이름을 광고 패킷에 포함하지 않는 경우가 많아요.
  • 하나를 선택했는데 게이지가 반응이 없거나 계속 차갑기만 하면, [다시 스캔]으로 다른 기기를 시도해보세요. 맞는 기기라면 실제로 가까워질 때 게이지가 반응해요.

찾는 기기가 신호를 보내고 있어야 해요

  • 워치·이어폰·트래커류는 대부분 주기적으로 블루투스 신호(광고 패킷)를 보내서 잘 잡혀요.
  • 휴대폰은 평소엔 신호를 잘 보내지 않아요. 설정에서 블루투스를 켜고 "검색 가능" 또는 페어링 대기 상태로 두면 더 잘 잡혀요.
  • 이미 다른 기기와 연결(페어링)되어 있으면 신호가 약하게 잡히거나 안 잡힐 수 있어요.

거리 추정에 대해

  • 신호 세기(dBm)는 참고용이에요. 벽·가구·다른 전자기기 때문에 흔들릴 수 있어요. 정확한 거리보다는 "가까워지는지 멀어지는지" 방향을 보는 용도로 써주세요.

실시간 추적이 안 될 때

  • 일부 브라우저는 실시간 신호 감시 기능이 실험 단계예요. chrome://flags에서 "Experimental Web Platform features"를 켜보세요.
  • 그래도 안 되면 [다시 스캔] 버튼으로 반복 스캔하면서, 기기 선택 창에 표시되는 신호 아이콘을 비교해보세요.

Web Bluetooth는 사용자가 직접 선택한 기기에만 접근해요. 이 페이지는 어떤 정보도 서버로 전송하거나 저장하지 않아요.
