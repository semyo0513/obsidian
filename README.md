# 🌌 창시디언 (Changsidian) Web App

**창시디언**은 옵시디언(Obsidian)과 유사한 경험을 웹 브라우저에서 바로 제공하는 **AI 지식 그래프 노트 웹 애플리케이션**입니다. 복잡한 설치 없이 브라우저만 있으면 언제 어디서나 당신만의 지식 베이스를 구축하고 탐색할 수 있습니다.

---

## ✨ 주요 기능 (Features)

### 1. 🕸️ 인터랙티브 지식 그래프 뷰 (Knowledge Graph View)
- 노트 간의 연결 관계를 시각적인 그래프로 보여줍니다.
- **노트 미리보기**: 그래프의 노드를 클릭하면 화면 이동 없이 오른쪽에 해당 노트가 바로 열립니다.
- **직관적인 탐색**: 클릭한 노드와 직접 연결된 노드만 강조되고 나머지는 흐려져서 지식의 흐름을 쉽게 파악할 수 있습니다.
- 줌 인/아웃, 노드 드래그 등 부드러운 상호작용을 지원합니다.

### 2. 🤖 AI 질의응답 (AI Q&A)
- 작성한 지식을 바탕으로 AI에게 질문하고 답변을 받을 수 있는 스마트한 기능을 제공합니다. 

### 3. ☁️ 강력한 동기화 및 저장 방식
- **구글 드라이브 양방향 동기화**: 노션처럼 별도 중계 서버 없이 브라우저에서 직접 구글 드라이브와 실시간 동기화합니다.
- **로컬 폴더 연동 (웹)**: 웹에서 실행하더라도 기기의 로컬 폴더를 지정하여 `.md` 파일로 직접 저장하고 불러올 수 있습니다. (크롬, 엣지 데스크톱 브라우저 지원)
- **독립 실행 및 PWA 지원**: 오프라인 상태나 로컬 스토리지 환경에서도 작동하며, PWA를 지원하여 모바일이나 데스크톱에 앱처럼 설치할 수 있습니다.

### 4. 📝 효율적인 노트 작성 및 관리
- **위키링크(`[[ ]]`) 자동 연결**: 편집 화면에서 제목을 검색하여 다른 노트로 연결되는 위키링크를 쉽게 삽입할 수 있습니다.
- **폴더(범주) 분류**: 노트를 폴더별로 지정하고 사이드바에서 필터링하여 체계적으로 관리할 수 있습니다.
- **모바일 최적화 UX**: 좁은 모바일 화면을 배려한 햄버거(☰) 메뉴 및 반응형 레이아웃을 제공합니다.

## 🚀 시작하기 (Getting Started)

창시디언 웹앱은 단일 HTML 파일(`index.html`)로 동작하도록 설계되어 배포 및 사용이 매우 간편합니다.

1. **웹에서 바로 사용 (GitHub Pages)**:
   - 저장소를 포크하거나 클론한 뒤, GitHub Pages를 통해 배포하면 어디서든 접속할 수 있는 웹 메모장으로 활용 가능합니다.
2. **로컬 환경에서 사용**:
   - `index.html` 파일을 브라우저로 열기만 해도 브라우저 내장 스토리지(localStorage)를 통해 완벽하게 작동합니다.

> **💡 구글 드라이브 연동 팁**  
> 구글 드라이브 연동을 위해서는 Google Cloud Console에서 '웹 애플리케이션' 유형의 OAuth 클라이언트 ID를 발급받아 설정에서 입력해주시면 됩니다.
